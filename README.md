# Akanksha Patil — Portfolio

Personal portfolio website for Akanksha Patil, a Frontend Engineer
specializing in React.js, Next.js, TypeScript, performance
optimization, and technical SEO.

## Live Website

https://akanksha-portfolio-tan.vercel.app/

## Tech Stack

- React.js
- JavaScript
- Vite
- CSS
- Supabase
- Vercel

## Features

- Responsive portfolio design
- Responsive navigation
- Project showcase
- Professional experience
- Technical skills
- Contact section
- Supabase-powered visitor counter
- Session-based visitor tracking

## Visitor Counter

The portfolio uses a Vercel serverless API and Supabase
PostgreSQL function to maintain the visitor count.

Architecture:

Portfolio → Vercel API → Supabase
